请直接安装这个“BGM 无缝切换版”项目。

重要架构：

- index.html 是应用外壳和唯一播放器；
- home.html 才是原视觉首页；
- characters.html、plot.html、world.html、map.html 是内部内容页；
- 内容页通过 postMessage 请求 index.html 切换 iframe；
- 播放器不能重新放回内容页，否则音乐会再次因整页卸载而中断。

执行步骤：

1. 备份现有项目。
2. 用压缩包中的全部文件覆盖项目，不要只覆盖五个旧 HTML。
3. 保留用户本机现有的 assets/audio 和 assets/portraits 实际文件。
4. 从 index.html 启动。
5. 播放一首 BGM，记录当前秒数。
6. 依次切换人物关系、情节发展、世界观、地图和首页。
7. 确认播放器中的当前秒数连续增长，歌曲没有重新加载。
8. 测试浏览器前进／后退，音乐继续播放。
9. 测试人物弹窗、筛选、地图切换、世界观标签和互动音效。
10. 检查控制台无 JavaScript 错误。

禁止：
- 将 home.html 改名为 index.html；
- 删除 index.html 中的 iframe；
- 在每个内容页重新创建 Audio；
- 将导航改回 location.href 整页刷新；
- 删除 fanren-persistent-shell-bridge。

# 凡人修仙传阅读助手 · BGM 无缝切换版

## 核心修复

原版本的播放器分别存在于五个 HTML 中。点击人物、剧情、世界观或地图时，
浏览器会卸载旧页面并销毁 `<audio>`，新页面再创建新的音频对象，因此必然发生中断。

本版本改为：

- `index.html`：持续存在的应用外壳和唯一音乐播放器
- `home.html`：原首页视觉内容
- `characters.html`：人物关系
- `plot.html`：情节发展
- `world.html`：世界观
- `map.html`：地图

五个内容页面在 `index.html` 的内部框架中切换，播放器不被销毁，所以 BGM
会保持同一音频对象、同一播放位置和同一音量连续播放。

## 使用方式

必须从：

```text
index.html
```

进入网站。不要把 `home.html` 改回 `index.html`。

直接打开 `characters.html`、`plot.html` 等子页面时，页面会自动跳回应用外壳，
并打开对应版块。

## 已支持

- 人物、剧情、世界观、地图之间切换不中断 BGM
- 浏览器前进／后退不中断 BGM
- 曲目、进度、音量、静音和播放器展开状态保存
- 完整刷新网站后恢复上次进度
- 刷新后的自动续播仍受浏览器自动播放规则限制，首次点击后恢复
- 子页面按钮、人物卡、地图区域继续触发玉磬互动音效
- 手机端播放器保持右下角悬浮

## 资源目录

保留原项目：

```text
assets/audio/
assets/portraits/
```

四首音乐文件名仍为：

```text

```

## 交给 Claude Code

请直接覆盖整个项目目录，不要只覆盖旧的五个 HTML，因为新版多了 `home.html`，
并且 `index.html` 已变为持续播放器外壳。

不要：

- 把 `home.html` 重命名回 `index.html`
- 把播放器重新复制进各子页面
- 删除子页面末尾的 `fanren-persistent-shell-bridge`
- 把 iframe 导航改回普通整页跳转

需要检查：

1. 从 `index.html` 打开；
2. 播放 BGM；
3. 连续切换人物、剧情、世界观、地图；
4. 确认歌曲时间持续增加，没有回到 0；
5. 使用浏览器前进和后退，音乐也应继续；
6. 刷新网站时允许出现一次“继续上次播放”，这是浏览器自动播放策略，不是切页中断。

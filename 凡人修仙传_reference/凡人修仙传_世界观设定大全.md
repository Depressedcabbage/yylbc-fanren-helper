## 一、人族修炼境界完整列表（从低到高）

### 下境界（人界阶段 / Mortal Realm）

---

#### 1. 炼气期 (Qi Condensation / Lianqi)

| 属性 | 内容 |
|------|------|
| **小阶段** | 炼气一层至十三层（共13层） |
| **寿元** | 约 100-120 岁 |
| **核心特征** | 凡人踏入修仙的第一步，吸收天地灵气，体内灵气为**气态** |
| **典型能力** | 拥有初步神识（数丈范围）、可施展基础法术（火球术、御风术、控物术等） |
| **突破条件** | 需筑基丹辅以突破；天灵根者无需筑基丹即可自行筑基 |
| **韩立历程** | 10岁被墨大夫收入七玄门，以长春功修炼，14岁突破至炼气四层；靠掌天瓶催熟灵药、大量嗑药，最终25岁修炼至炼气十三层大圆满 |

**炼气期细分：**
- 炼气1-3层：初窥门径，身体素质略强于凡人
- 炼气4-6层：可施展中阶法术，神识范围扩大
- 炼气7-9层：可御器飞行（需飞行法器）
- 炼气10-12层：开始接触修炼瓶颈
- 炼气13层（大圆满）：灵气满溢，准备筑基

---

#### 2. 筑基期 (Foundation Establishment / Zhuji)

| 属性 | 内容 |
|------|------|
| **小阶段** | 初期、中期、后期（筑基巅峰称"假丹境"） |
| **寿元** | 约 200-250 岁 |
| **核心特征** | 灵气由气态压缩为**液态**真元，丹田开辟 |
| **典型能力** | 可御剑飞行（不需飞行法器）、掌握辟谷之术（可不食人间烟火）、神识范围数十丈；可炼制符宝 |
| **突破条件** | 需服用筑基丹（以提高成功几率）；天灵根无需筑基丹；异灵根若无筑基丹终身卡在炼气期 |
| **关键丹药** | 筑基丹（升仙丸）——以玉髓芝、紫猴花、天灵果为主药，辅以三十一种药材 |
| **韩立历程** | 服用八颗筑基丹，25岁于黄枫谷筑基成功 |

#### 3. 结丹期 (Core Formation / Jiedan)

| 属性 | 内容 |
|------|------|
| **小阶段** | 初期、中期、后期（结丹巅峰称"假婴境"） |
| **寿元** | 约 500-600 岁 |
| **核心特征** | 液态真元压缩凝聚为**金丹**，丹田核心形成 |
| **典型能力** | 可炼制本命法宝、神识范围数百丈、丹火可用于炼丹炼器 |
| **突破条件** | 需开辟紫府、形成真元漩涡、凝液成丹；辅助丹药：雪灵水、天火液、降尘丹 |
| **韩立历程** | 修炼三转重元功，收集雪灵水、天火液、降尘丹，闭关六十年，**126岁**成功结丹 |

---

#### 4. 元婴期 (Nascent Soul / Yuanying)

| 属性 | 内容 |
|------|------|
| **小阶段** | 初期、中期、后期 |
| **寿元** | 约 1000-1200 岁 |
| **核心特征** | 金丹碎裂化为**元婴**（寸许小人形态），藏于丹田，为修士"第二生命" |
| **典型能力** | 元婴可脱离肉身独立行动、夺舍重生（肉身被毁可元婴出窍夺舍他人）、瞬移（元婴期修士可在一定距离内瞬移）；神识覆盖百里 |
| **突破条件** | 金丹碎裂、元婴凝聚；需九曲灵参丹提高结婴成功率；需渡心魔劫。人界修士上限基本为此境界 |
| **韩立历程** | 服用九曲灵参丹、定灵丹、补天丹等，修炼大衍决第四层增强神识，**217岁**于落云宗成功凝结元婴 |

---

#### 5. 化神期 (Deity Transformation / Huashen)

| 属性 | 内容 |
|------|------|
| **小阶段** | 初期、中期、后期 |
| **寿元** | 约 2000-2500 岁 |
| **核心特征** | 元婴成长为幼年/少年状态，可调动天地灵气作战；开始接触天地法则 |
| **典型能力** | 可初步操控天地元气、神识覆盖千里；进入此境界后人界已有飞升的"资格" |
| **突破条件** | 人界极难突破，因上古大战后人界灵气被魔气污染，修士最多修炼到化神初期即止 |
| **特殊说明** | 人界有数位化神初期修士（向之礼、风老怪、呼老魔等），但无法更进一步，需"偷渡"飞升灵界 |
| **韩立历程** | 服用魔炼天元丹，于大晋万妖谷突破至化神期，后通过空间节点"偷渡"至灵界 |

---

#### 6. 炼虚期 (Void Refinement / Lianxu)

| 属性 | 内容 |
|------|------|
| **小阶段** | 初期、中期、后期 |
| **寿元** | 理论上只要有足够天地元气则寿元无穷；但需渡3000年一次大天劫，一般修士能扛过约3次，实际存活约1.2万年 |

| **天劫** | 每3000年一次大天劫，以法则具象化攻击为主；极限约9次 |

#### 7. 合体期 (Integration / Heti)

| 属性 | 内容 |
|------|------|
| **小阶段** | 初期、中期、后期 |

| **典型能力** | 可初步施展领域之力，战力远超炼虚期数倍 |

#### 8. 大乘期 / 渡劫期 (Grand Ascension / Dacheng + Du Jie)

| 属性 | 内容 |
|------|------|
| **小阶段** | 初期、中期、后期 → 突破后进入**渡劫期**（飞升准备阶段） |
| **寿元** | 至少10万年，顶级大乘可达百万年 |
| **核心特征** | 元婴成人体态，脱离肉身限制；掌握两种及以上属性法则；肩负种族兴衰 |
| **典型能力** | 可施展完整灵域、操控天地法则；渡劫期修士更被视为"另一个阶层的人" |
| **突破条件** | 需完整掌握法则之力；渡劫期后需渡过飞升之劫方可进入仙界 |
| **天劫** | 大天劫每3000年一次，飞升之劫为终极考验（雷劫震天，劫云可覆盖十万里） |
| **特殊说明** | 灵界因小南洲界群与仙界失联，大乘修士极难正常飞升；渡劫期修士被称为"半仙" |

## 一、功法体系（修炼功法 / Cultivation Arts）

### 功法等级（人界/灵界通用分级）
- **黄级**：基础功法，炼气筑基修士所用
- **玄级**：中等功法，结丹元婴修士所用
- **地级**：上等功法，化神炼虚修士所用
- **天级**：顶级功法，合体大乘修士所用

---

### 韩立修炼过的主要功法

#### 1. 长春功 (Eternal Spring Art)
- 等级：黄级基础功法
- 来源：墨大夫传授，七玄门所得
- 效果：木属性基础炼气功法
- 阶段：炼气期使用，后因无名口诀而废弃

#### 2. 青元剑诀 (Qingyuan Sword Art)
- 等级：**天级功法**
- 来源：人界传奇修士**青元子**所创。韩立筑基后从黄枫谷获得前九层（金页补全至十三层），后在灵界冥河之地遇到青元子本人获得完整版
- 层次：共十三层，韩立全部修炼圆满
- 效果：
  - 人界阶段：结丹期凝练**七十二口青竹蜂云剑**；元婴期衍生**大庚剑阵**；化神期进阶**春黎剑阵**
  - 灵界阶段：完整三套剑阵，大乘期每套剑阵可斩杀一位大乘修士
  - 附带神通：青元剑芒、护体剑盾、剑影分光术
- 贯穿：人界 → 灵界 → 仙界（韩立最主要的主修功法）

#### 3. 大衍决 (Dayan Jue - Grand Development Tactics)
- 等级：**天级（神识类）**
- 来源：千竹教镇派法典，由**大衍神君**（人界最妖孽天才修士）自创。韩立从千竹教叛徒获得前几层，后赴极西之地救出大衍神君获完整版
- 本质：仙界禁术**炼神术**的简化版，但**无副作用**（炼神术消耗下几世修炼天赋）
- 效果：
  - 修炼圆满后神识暴涨**两倍**，韩立结丹期神识媲美元婴期
  - 附带"惊神刺"等神识攻击手段
  - 超强分神能力→同时操控上百个傀儡+噬金虫群
- 影响：韩立将此功传授给李元究，后者修炼成为**九元道祖**

#### 4. 梵圣真魔功 (Brahma Sacred Demon Art)
- 等级：**天级（炼体类）**
- 来源：由三部分融合自创——**明王决**（佛门）、**托天魔功**（魔道）、**梵圣妖功/梵圣真片**（妖族）
- 效果：
  - 法体双修，肉身强度大幅提升
  - 配套炼制**法相金身**，可分裂出独立战斗个体
  - 可创造**三头六臂法相**
  - **涅槃三变**（最强神通）：第三层涅槃圣体→肉身媲美**真仙**，能一剑斩杀真灵（阳鹿），可连续催动玄天斩灵剑
- 阶段：灵界 → 仙界（韩立灵界核心功法）

#### 5. 三转重元功 (Three Revolutions Origin Art)
- 效果：可散功重修三次，每次重修后法力比同阶更加精纯深厚
- 韩立用法：结丹前散功重修，积累深厚法力

#### 6. 炼神术 (Spirit Refinement Art)
- 等级：仙界禁术
- 效果：大幅增强神识，但有巨大副作用（消耗下几世修炼天赋）
- 阶段：灵界后期取代大衍决

#### 7. 万剑诀 (Ten Thousand Swords Art)
- 阶段：仙界篇使用

## 五、飞升机制

### 人界 → 灵界
| 方式 | 说明 |
|------|------|
| **正常飞升** | 上古时期：修炼至化神后期，自然感应灵界飞升通道 |
| **空间节点偷渡** | 现今唯一方式：通过空间节点强行进入灵界，**风险极高**。向之礼等三大化神修士联手通过节点均陨落。韩立凭借强大肉身+众多法宝成功渡过 |
| **逆灵通道** | 特殊通道，从灵界进入人界的单向通道（从上往下） |
| **魔化飞升** | 若被真魔气灌体化为魔族，则飞升**魔界**而非灵界 |

### 灵界 → 仙界
- 大乘期大圆满后进入渡劫期
- 渡过飞升雷劫
- 因小南洲界群与仙界失联，飞升极为艰难
- 韩立通过轮回殿遗留通道+自身实力飞升

### 核心规则
1. **强制性上升**：达到当前界面境界上限后受界面之力压制，不得不飞升
2. **上升成本递增**：灵界修炼以数十万年计，仙界以数百万年计
3. **高阶降临限制**：上界面修士可压制修为降临下界面，但代价较大

# 第四部分：灵根体系 (Spiritual Roots)

---

## 一、灵根完整分类（由优到劣）

### 1. 天灵根（单灵根）—— 顶级资质
| 属性 | 内容 |
|------|------|
| 定义 | 只有**一种属性**的纯净灵根（金/木/水/火/土纯一） |
| 灵根充裕度 | 极高 |
| 修炼速度 | 比普通灵根快**数倍** |
| 瓶颈 | **从炼气期一路到结丹初期没有任何瓶颈**——无需筑基丹即可自行筑基、自行结丹 |
| 结丹后 | 出现正常瓶颈，优势消失 |
| 化神→炼虚 | 需补全五行灵根，天灵根需额外补四行（灵界补灵根很简单，人界比登天还难） |
| 代表 | 南宫婉、燕如嫣、天星双圣 |

### 2. 异灵根/变异灵根 —— 顶级资质（有短板）
| 属性 | 内容 |
|------|------|
| 定义 | 两种或三种五行属性混合异变升华形成：风灵根、雷灵根、冰灵根、暗灵根等 |
| 修炼速度 | **与天灵根完全相同**，不分伯仲 |
| 瓶颈 | **有瓶颈！**——若无筑基丹终身卡在炼气期；结丹也需丹药和灵物辅助 |
| 战力优势 | 同阶战力远超普通修士；结丹后天灵根优势消失，异灵根仍保持战力强项 |
| 代表 | 黄枫谷陆师兄(风)、鬼灵门王婵(暗)、慕容兄弟(雷) |

### 3. 双灵根（真灵根）—— 中上资质
- 两种属性灵根
- 修炼速度较快，有较大概率筑基
- 上限约结丹至元婴

### 4. 三灵根（真灵根）—— 中等资质
- 三种属性灵根
- 大门派招收弟子的**最低门槛**
- 有筑基可能，结丹基本无望

### 5. 四灵根（伪灵根）—— 劣等资质
- 四种属性灵根，杂且不充裕
- 正常情况筑基都不可能
- 上限约炼气十层
- **韩立的灵根类型**：水、木、火、土四属性，缺金属性

### 6. 五灵根（废灵根）—— 最差资质
- 五种属性俱全
- 上限约炼气五六层
- 若无海量资源，终其一生在炼气期徘徊

---

## 二、灵根核心规则

> **灵根越少，资质越好** —— 凡人世界核心规则

### 前期（结丹及以前）
天灵根 > 异灵根 > 双灵根 > 三灵根 > 四灵根 >> 五灵根

### 化神→炼虚转折
需要**五行合一**补全五行灵根：
- 天灵根需额外补四行 → 人界极难，灵界很容易
- 多灵根自带多个属性 → 补全难度反而较低
- 但在灵界补灵根"如同吃饭喝水"，天灵根优势依然存在

### 元婴期之后
灵根重要性大幅下降，**机缘和气运远比灵根重要**

---

## 三、韩立的特殊情况

### 灵根：四属性伪灵根
灵根极差，正常情况下毕生无法筑基。

### 翻盘方式
1. **掌天瓶（核心）**：夜晚吸收月光凝聚**绿液**，可催熟灵药，使韩立以"嗑药"方式突破灵根限制
2. **大量丹药**：凭借催熟的灵药大量炼制丹药
3. **补天丹**：弥补灵根不纯、精炼先天灵根
4. **各种奇遇**：不断获得高阶功法、丹药、资源

### 结论
韩立的四属性伪灵根 + 掌天瓶催熟体系 = "最好的废灵根遇上了最强的外挂"
